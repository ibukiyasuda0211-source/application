# ⚾ ダイヤモンド・ライフ 〜プロ野球人生シミュレーション〜

ひとりのプロ野球選手の人生を、ドラフト指名から引退まで体験できるブラウザゲームです。
（パワプロの「マイライフ」のような遊び方をイメージしています）

## 遊び方

1. `index.html` をブラウザで開く（サーバー不要。GitHub Pages などにそのまま置けます）
2. 選手名・ポジション・投打・経歴（高卒／大卒／社会人）・成長タイプを決めてドラフト会議へ
3. 1週間ごとに行動（練習・休養・遊び・デート）を選ぶ
4. 練習でたまった **経験点** を「能力アップ」画面で使って能力を上げる
5. 2軍で結果を出して首脳陣の評価を上げ、1軍昇格 → レギュラー → タイトルを目指す
6. オフには契約更改。FA移籍・戦力外・引退も…

## 主な要素

| 要素 | 内容 |
| --- | --- |
| 能力 | 野手：ミート／パワー／走力／肩力／守備力／捕球、投手：球速／コントロール／スタミナ／変化球（最大5球種） |
| 特殊能力 | チャンス◯、パワーヒッター、ノビ◯、奪三振 など17種 |
| 1年の流れ | 自主トレ → 春季キャンプ → オープン戦 → ペナントレース（143試合）→ CS・日本シリーズ → 表彰 → 契約更改 |
| 試合 | 1打席ごとのシミュレーション。成績・チーム順位・タイトル争いがリアルタイムに変化 |
| タイトル・表彰 | 首位打者・本塁打王・三冠王・最多勝・沢村賞・MVP・新人王・ベストナイン など |
| イベント | 先輩・コーチ・ライバル・ファン・恋愛・結婚・子供・ケガ・CM出演 など約30種 |
| 人生 | 年俸・所持金・ショップ、FA移籍、戦力外通告とトライアウト、引退後のエンディング（名球会・殿堂入り） |
| セーブ | ブラウザの localStorage に3スロット自動保存 |

## ファイル構成

```
index.html
css/style.css
js/util.js     汎用関数
js/data.js     球団・名前・特殊能力・ショップなどのデータ
js/player.js   選手生成・能力・成長・衰え
js/sim.js      打席／投球シミュレーション・WAR
js/events.js   ランダムイベント
js/game.js     週送り・年間スケジュール・契約・引退・セーブ
js/ui.js       画面描画と操作
```

球団・選手名はすべて架空のものです。
