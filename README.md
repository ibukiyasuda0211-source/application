# ⚾ ダイヤモンド・ライフ 〜プロ野球人生シミュレーション〜

ひとりのプロ野球選手の人生を、ドラフト指名から引退まで体験できるブラウザゲームです。
（パワプロの「マイライフ」のような遊び方をイメージしています）

## 遊び方

1. `index.html` をブラウザで開く（サーバー不要。GitHub Pages などにそのまま置けます）
2. 選手名（苗字・名前）・ポジション・武器（パワーがある／安打製造機／俊足／剛速球 など）・投打・経歴（高卒／大卒／社会人）・成長タイプを決めてドラフト会議へ
3. 毎週「練習」と「オフの過ごし方」をひとつずつ選ぶ
4. 練習でたまった **経験点** を「能力アップ」画面で使って能力を上げる
5. オフは自由：先輩と食事、デート、趣味、帰省、取材、自主練…出会いと人間関係が人生を変える
6. 2軍で結果を出して首脳陣の評価を上げ、1軍昇格 → レギュラー → タイトルを目指す
7. オフには契約更改。FA移籍・戦力外・引退、そして第二の人生へ

## 開発者向け

Node.js があれば、追加のインストールなしで動きます。

| コマンド | 内容 |
| --- | --- |
| `npm test` | 自動テスト。日程（143試合・交流戦）、試合結果とスコアボードの整合性、ドラフト同期とチームメイトの一致、入団からエンディングまでの通しプレイ、セーブの書き出し・読み込み、侍ジャパン（合宿・交流・役割・本大会・シリーズ）を確かめる |
| `npm run balance` | おまかせで何十人分もの野球人生を走らせ、通算成績・タイトル・お金・充実度の分布を表示する（`npm run balance -- 100` で人数指定） |
| `npm run build` | すべてを1ファイルにまとめた `dist/diamond-life.html` をつくる |

### バランスの目安

`npm run balance` で「おまかせ」60人分を走らせた結果（中央値）。自分で丁寧に育てれば、これより上を目指せる前提です。

| 項目 | 調整前 | 調整後 | 参考（NPB） |
| --- | --- | --- | --- |
| 引退した年齢 | 44歳 | 38歳 | レギュラー経験者で36〜38歳くらい |
| 通算WAR | 72 | 21 | 長く活躍したレギュラーで20〜30 |
| 通算安打（野手） | 3,669 | 1,760 | 2,000本は一握り |
| 名球会 | 98% | 22% | |
| メジャー挑戦 | 100% | 5% | 毎年数人 |
| 最高年俸 | 22.5億円 | 1.2億円 | レギュラーで1億円前後 |

主な調整：素質（能力の伸びしろ）を下げて、素質を超えると経験点が大きく増える／コーチの指導などで素質を超えて伸びない／経験点はそれぞれ999まで／特殊能力と変化球のコストを上げた／衰えを少し早く強く／ベテランは休養日がある／打順で打席数が変わる／メジャーのオファーはWAR4.5以上の活躍が条件

### 機能の足し方（合図の仕組み）

本体の処理は決まった場所で合図を出し、追加機能はそれを受け取って動きます。既存の関数を上書きしないので、読み込み順や機能どうしの重なりで壊れにくくなっています。

```js
G.on('week:life', (s) => { /* 毎週の私生活のあと */ });
G.on('trainingMul', (m, s) => m * 1.1);          // 値を加工する（filter）
G.on('contractScene', (s) => G.underContract(s)); // true を返すと本体の処理を止める（blocked）
```

主な合図：`intl:selected` `intl:accepted` `intl:finish` `newGame` `week:life` `week:after` `year:life` `stories` `private` `buzz` `season:week` `scheduled` `seasonEnd` `leaders` `scene:resolved` `retire` `finishLife` `after:start` `after:week` `after:newYear` `after:seasonEnd` `joinMLB` `joinNPB` `ownGame:prepare` `ownGame:result` `ach:before` `invest:beforeBuy` `migrate`（値の加工：`trainingMul` `injuryMul` `afterIncome` `extraActions` `canJointTrain` `trainingOptions` `trainingDone` `canTalkMate` `intlFinalSpeech`、止める：`contractScene` `releaseCheck` `mlbCheck` `openGames`）

球団・選手名はすべて架空のものです。
